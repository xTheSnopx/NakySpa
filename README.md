# NakySpa

Este proyecto es una página web sencilla para NakySpa, diseñada para mostrar información sobre los servicios del spa, imágenes y estilos personalizados.

## Estructura del proyecto

- **index.html**: Página principal del sitio web.
- **estilos.css**: Archivo de estilos para la página web.
- **imagenes/**: Carpeta que contiene imágenes utilizadas en la página.
- **README.md**: Documentación del proyecto.

## Cómo usar

1. Abre el archivo index.html en tu navegador para ver la página web.
2. Puedes modificar estilos.css para cambiar la apariencia del sitio.
3. Agrega o reemplaza imágenes en la carpeta imagenes/ según tus necesidades.

## Personalización

- Edita el contenido de index.html para actualizar la información del spa, servicios, horarios, etc.
- Cambia los estilos en estilos.css para adaptar el diseño a tu preferencia.
- Añade nuevas imágenes en la carpeta imagenes/ para mejorar la presentación visual.
